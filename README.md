# しょうがくせいの まほうつかい

> [kids-game](https://github.com/hirofumi-morita/kids-game) の 「にねんせいの だいぼうけん」をコピーした土台です。
> 今の中身はコピー元とまったく同じで、タイトル文字だけ変えてあります。
> ここから あたらしい 横スクロールゲームに つくりかえていきます。

かさを持った小学2年生の**女の子か男の子**（タイトルで選べます）が、ネコやタヌキに変身しながら進む横スクロールのジャンプアクションゲームです。
**ステージ1**は通学路を歩いて学校の校門へ。**ステージ2**は川をおよいで渡り、坂をのぼり、
ネコでかべをよじのぼっておうちへ帰ります。どちらのステージもおうちの中を探検できます。

HTML 1ファイルだけで動きます。`index.html` をブラウザで開けばすぐ遊べます（ビルド不要・外部ライブラリなし）。

## そうさ

| そうさ | キー | タッチ |
| --- | --- | --- |
| うごく | `←` `→` / `A` `D` | ◀ ▶ |
| ジャンプ | `スペース` / `↑` / `W`（長押しで高く） | ジャンプ |
| こうげき | `K` / `J` / `X` / `Z` / `Shift` | こうげき |
| しらべる・ドアにはいる | `E` / `Enter` / `↓` | しらべる |
| へんしん | `C`（順番に）／`1` `2` `3`（直接） | へんしん |
| キャラを えらぶ（タイトル） | `←` `→` | ◀ ▶ |
| そらで とぶ／2段ジャンプ | 空中で もう一度 `スペース` | ジャンプ |
| およぐ（水の中） | `スペース` を押しっぱなし | ジャンプ |
| やりなおし | `R` | － |
| おとの オン／オフ | `M` | 「おと」ボタン |

## キャラを えらぶ

タイトル画面で `←` `→` を押して **おんなのこ** / **おとこのこ** を選びます。どちらもかさで攻撃でき、ネコ・タヌキに変身できます。違うのは空中での動きだけです。

| キャラ | 空中で できること |
| --- | --- |
| おんなのこ | スカートが自動でふくらんでゆっくり落ちる。空中でもう一度 `スペース` を押して押しっぱなしにすると**自動で飛ぶ**。落ちながら `E` でかさも開いてさらにゆっくり |
| おとこのこ | スカートがないので飛べない。そのかわり空中でもう一度 `スペース` で**2段ジャンプ**（2段まで） |

## 3つの すがた

| すがた | とくちょう | とくべつな ちから |
| --- | --- | --- |
| おんなのこ／おとこのこ | ふつうの うごき | かさを ふって こうげき。空中での動きは上の「キャラを えらぶ」を参照 |
| ネコ | はやく はしれる・小さい | **2かいジャンプ**。ひっかき攻撃。1マスしかない**ネコ専用の穴**を通れる。かべに向かって歩くと**かべにつかまり、スペースでよじのぼる** |
| タヌキ | おそいけど つよい | 地上で**たいあたり**、空中で**ヒップドロップ**。どちらも**レンガを壊せる** |

すがたを変えると当たり判定の大きさも変わります。せまい場所で大きい姿になろうとすると
「ここでは むり！」と出て変身できません。

## あそびかた

- ★（ハナマル）を集めるとスコアになります。はてなブロックは下から頭で突き上げると★が出ます。
- カラスとハチは、こうげきするか、頭から踏むと倒せます。
- 通学路（ステージ1）には**入れるおうちが3軒**あります。ドアの前で `E`。
  中の テーブル・ほんだな・たんす・ベッド・たからばこ を `E` で調べると★がもらえます（ステージ1は全部で15か所）。
- かくし部屋が2つあります。
  - **みどりの おうち** … 奥の壁にネコ専用の穴。ネコに変身して通ると「やねうら」へ。
  - **きいろい おうち** … レンガの壁。タヌキに変身して壊すと「ちか」へ。
- ハートは5つ。穴に落ちるか敵に当たると1つ減り、途中のピンクの旗（チェックポイント）から再開します。
- 校門にたどり着くとクリアです。クリア後、スペースキーでステージ2へ進みます。

## ステージ2「かわを わたって おうちへ」

タイトル画面で `2` を押すと、ステージ2から直接始められます。

- **かわ・いけ** … 中に入るとゆっくり沈みます。`スペース` を押しっぱなしにすると浮かび上がり、
  およいで渡れます。水面から出るときにスペースを押していると、いきおいよく飛び出します。
  水の中には魚がいるので、こうげきするか よけて進みます。タヌキは重くて沈みやすいので、
  川を渡るときは おんなのこ か ネコ がおすすめです。
- **さか** … 45度の坂をのぼったり下ったりします。1マスの段差は自動で乗り越えます。
- **たかい かべ** … ネコに変身してかべに向かって歩くとつかまり、`スペース` でよじのぼれます。
  てっぺんには★が並んでいます。
- **かわべの こや** … 川のそばの青いおうち。中にもネコ用のかべのぼりがあります。
- ゴールは**おうち**です。

## しくみ

- Canvas 2D + 素の JavaScript。絵はすべてコードで図形を描いています（画像ファイルなし）。
- 物理は 60Hz 固定ステップ。タイルグリッドに対して X軸・Y軸を別々に解決する AABB 判定です。
- タイルの種類：地面 / 足場 / はてなブロック / レンガ（タヌキだけが壊せる） / 室内の壁 / 室内の床 /
  水 / 坂（右上がり・左上がり）。坂の下は「坂の埋め」タイルで、当たり判定を持たせずに見た目だけ埋めています。
- 坂の接地は、足元のタイルが坂なら 45度の面の高さに吸着させる方式です。
  体の下にそれより高い硬いタイルがあればそちらを優先し、坂と壁の境目でつっかえないようにしています。
- 水中は重力・最高速度を下げ、ジャンプキーで上向きの力を加える簡単な浮力モデルです。
- ステージは `STAGE_DEFS`（ステージ1 / ステージ2）で定義し、それぞれが「エリア」の集まりを持ちます。
  - そと（`MAIN_*` / `S2_*` の配列）… 地面・足場・坂・水・コイン・敵・おうちのドア・看板を配列で定義。
  - 中（`ROOMS` の配列）… 部屋ごとに 足場・レンガ・コイン・家具・ドアを座標で定義。
  `ROOM_LINKS` がどのドアがどの部屋につながるかを持っています。
- すがたの性能は `FORMS`（大きさ・速さ・ジャンプ力・重力）にまとまっています。
- 選んだキャラは `hero`（`'girl'` / `'boy'`）が持ちます。内部のすがたはどちらも `girl` のままで、
  `isGirl()` / `isBoy()` / `airCap()` が空中の挙動を、`drawGirl` / `drawBoy` が見た目を切り替えます。
- 文字は Google Fonts（M PLUS Rounded 1c / Mochiy Pop One）。オフラインでも代替フォントで動きます。
