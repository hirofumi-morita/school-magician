# しょうがくせいの まほうつかい

つえを もった しょうがくせいの まほうつかいが、**まおうの てした**を まほうで たおしながら
みちを すすみ、**★を 50こ** あつめて **おしろの もん**を ひらき、おくに いる
**まおうの おうさま**と たたかう 横スクロールアクションゲームです。

HTML 1ファイルだけで動きます。`index.html` をブラウザで開けばすぐ遊べます（ビルド不要・外部ライブラリなし）。

> [kids-game](https://github.com/hirofumi-morita/kids-game) の「にねんせいの だいぼうけん」を
> 土台にして、あたらしい ゲームに つくりかえました。

## そうさ

| そうさ | キー | タッチ |
| --- | --- | --- |
| うごく | `←` `→` / `A` `D` | ◀ ▶ |
| ジャンプ | `スペース` / `↑` / `W`（長押しで高く） | ジャンプ |
| **つえの まほうを はっしゃ** | `K` / `J` / `X` / `Z` / `Shift` | こうげき |
| しらべる・ドアにはいる | `E` / `Enter` / `↓` | しらべる |
| へんしん | `C`（順番に）／`1` `2` `3`（直接） | へんしん |
| キャラを えらぶ（タイトル） | `←` `→` | ◀ ▶ |
| そらで とぶ／2段ジャンプ | 空中で もう一度 `スペース` | ジャンプ |
| やりなおし（**さいしょから！**） | `R` | － |
| おとの オン／オフ | `M` | 「おと」ボタン |

タイトルで `スペース`＝ステージ1、`2`＝おしろ、`3`＝おまけの かわステージ。

ホームがめん（タイトル）には「**ちゅうい：R を おすと さいしょから に なるからね！**」と でます。

## つえの まほう

`K` を おすと つえの さきから **まほうだま**が とんでいきます。
とおくの てきも たおせて、いちどに 4つまで だせます。
ネコと タヌキに へんしんしている あいだは、つえの かわりに
ひっかき／たいあたり・ヒップドロップで たたかいます。

## リンゴ

| アイテム | こうか |
| --- | --- |
| 🍎 きんの リンゴ | **はてなブロックからだけ** でます。とると **7びょう むてき**。むてきの あいだは てきに ぶつかっても へいきで、ぶつかった てきは たおせます。どくリンゴも ききません |
| 🟣 どくの リンゴ | **ハートが 2 へります**。よけて とおろう |

むてきの のこり じかんは がめん左上に バーで でます。

## はてなブロック

下から あたまで つきあげるか、**つえの まほうだま**を あてると あきます。
中から つぎの どれかが とびだして、ブロックの うえに のります。

| でるもの | こうか | かくりつ |
| --- | --- | --- |
| ⭐ スター | ★が **3こ** ふえる（**じどうで もらえます**。ひろいに いかなくて OK） | 60% |
| ❤️ ハート | ハートが 1つ ふえる | 10% |
| 🧹 まほうの ほうき | **5びょう** とべる | 10% |
| 🍎 きんの リンゴ | 7びょう むてき | 10% |
| 🟣 どくの リンゴ | ハートが 2 へる | 10% |

なにが でるかは あけるまで わかりません。どくリンゴも でるので ちゅうい！

**おうさまの いる おしろの 中では、ほうきは でません**（そらに にげられないように、
かわりに スターが でます）。

## ともだちの いえと お助けアイテム

みちぞいに **ともだちの いえが 4けん** あります。ドアの まえで `E`。
中の テーブル・ほんだな・たんす・ベッド を `E` で しらべると ★が もらえます。

**たからばこ**だけは なかみが ちがいます。しらべると つぎの どれかが
**じどうで** もらえます（ひろいに いかなくて OK）。

| なかみ | こうか | かくりつ |
| --- | --- | --- |
| 🍎 きんの リンゴ | **12びょう むてき**（はてなブロックのは 7びょう） | 50% |
| 🟣 どくの リンゴ | **ハートが 1〜4 へる**（いくつ へるかは うんしだい） | 30% |
| ⭐ スター 2こ | ★が 2こ ふえる | 20% |
そして **お助けアイテム**が おいて あります。

| お助けアイテム | こうか |
| --- | --- |
| 🧹 まほうの ほうき | **9びょう そらを とべる**（ともだちの いえの ほうきは ながい！ はてなブロックから でる ほうきは 5びょう）。`スペース` を おしっぱなしで うかび、はなすと しずみます。のこり じかんは がめん左上に バーで でます |
| ❤️ ハート | **ハートが 1つ ふえる**（おんなのこは さいだい 7つ、おとこのこは 5つ） |

かくし部屋も 2つ あります。

- **みどりの いえ** … 奥の壁にネコ専用の穴。ネコに変身して通ると「やねうら」へ。
- **きいろい いえ** … レンガの壁。タヌキに変身して壊すと「ちか」へ。

## ★50こで おしろの もんが ひらく

ステージ1の おわりに **おしろの もん**が あります。
あつめた ★が **50こ**に なると もんが ひらいて、おしろの 中へ すすめます。
のこりの かずは もんに でます。がめん左上の `★ × いくつ ／50` も めやすです。

## ステージ2「まおうの おしろ」

おしろの 中は いしの ゆか。てしたが たくさん いて、
おくの **おうさまの ま**で ボスバトルに なります。

- **まおうの おうさま**（ハート 48つぶん＝つえLv1なら まほう 48はつ、Lv3なら 16ぱつ）。ちかづくと おきて たたかいが はじまります。
- たたかいが はじまる しゅんかんに、**じぶんの ハートが ぜんぶ かいふく**します。
- **どくだま**を なげてきます。そして **7びょうごとに てしたを 3たい よびます**（がめんに のこるのは 6たいまで）。
- **おうさまが よんだ てしたは ハートが 10こ**あって、あたまの うえに たいりょくバーが でます。みちに いる てしたの 3こより ずっと タフです。
- **まほうだま**＝1ダメージ、**ふみつけ**＝1ダメージ、**タヌキの ヒップドロップ**＝2ダメージ。
- ぶつかると ハートが へりますが、おうさまも しりもちを ついて はなれます。

たおすと クリアです。

## おうさまからの ごほうび

おうさまを たおすと、**がっこうで つかう もの**を ひとつ くれます。
`←` `→`（タッチは ◀ ▶）で えらんで、**`スペース` だけ**で けっていします
（`K` や `E` では きまらないので、まちがって とばす しんぱいが ありません）。

| ごほうび | |
| --- | --- |
| 📏 じょうぎ | まっすぐ ひける |
| 🧢 あかしろぼうし | たいいくで かぶる |
| ✏️ ふでばこ | えんぴつが はいる |

えらんだ ものは クリアの がめんに でます。

## つえの レベルアップ（ともだちの いえの 中だけ）

4けんの ともだちの いえの 中に、**つえレベルアップの だい**が 1つずつ あります。
つえは Lv3までなので、2けん まわれば さいこうレベルです。
さわると つえが つよく なります。

| レベル | まほうだま | てしたを たおすのに |
| --- | --- | --- |
| Lv1（さいしょ） | 1ダメージ | まほう 3はつ |
| Lv2 | 2ダメージ | まほう 2はつ |
| Lv3（さいこう） | 3ダメージ | まほう 1はつ |

レベルが あがると まほうだまが 大きく、いろも かわります。がめん左上の
「つえ ★★★」で いまの レベルが わかります。さいこうレベルで もう1つ さわると
★が 10こ もらえます。

**ステージ1 から ステージ2 へ すすむ とき、ハートの かずと つえの レベルは そのまま もちこせます。**

## まおうの てした

てしたは **ハートが 3こ**（つえの まほうで Lv1なら 3はつ）。ダメージを うけると
あたまの うえに のこりの ハートが でます。**おうさまが よんだ てしただけは ハート 10こ**で、
あたまの うえが バーに なります。ふみつけも 1ダメージ、タヌキの
ヒップドロップと むてき中の たいあたりは **1げきで たおせます**。
カラス・ハチ・さかなは これまでどおり 1げきです。

おうさまを たおして ごほうびを えらぶと けっかの がめんに なり、`スペース` で
**ホームがめん（キャラを えらぶ がめん）**に もどります。

## 3つの すがた

| すがた | とくちょう | とくべつな ちから |
| --- | --- | --- |
| おんなのこ | ハートが **7こ**。空中で もう **2かい** ジャンプできる **3だんジャンプ** | **つえの まほう**。スカートがふくらんでゆっくり落ちる。落ちながら `E` でもっとゆっくり |
| おとこのこ | ハートが **5こ**。空中で もう1かいの **2だんジャンプ** | **つえの まほう** |

ハートが ぜんぶ なくなると 「おっとっと！」の がめんに なり、`スペース` で
**キャラを えらぶ がめん（タイトル）**に もどります。そこで `←` `→` で
おんなのこ・おとこのこを えらびなおして、また はじめられます。
| ネコ | はやく はしれる・小さい | **2かいジャンプ**。ひっかき攻撃。1マスしかない**ネコ専用の穴**を通れる。かべに向かって歩くと**かべにつかまり、スペースでよじのぼる** |
| タヌキ | おそいけど つよい | 地上で**たいあたり**、空中で**ヒップドロップ**。どちらも**レンガを壊せる** |

すがたを変えると当たり判定の大きさも変わります。せまい場所で大きい姿になろうとすると
「ここでは むり！」と出て変身できません。

## おまけ：かわの ステージ

タイトルで `3` を押すと、川をおよいで渡り、坂をのぼり、ネコでかべをよじのぼる
ステージで遊べます（土台にした kids-game のステージ2）。

## しくみ

- Canvas 2D + 素の JavaScript。絵はすべてコードで図形を描いています（画像ファイルなし）。
- 物理は 60Hz 固定ステップ。タイルグリッドに対して X軸・Y軸を別々に解決する AABB 判定です。
- タイルの種類：地面 / 足場 / はてなブロック / レンガ（タヌキだけが壊せる） / 室内の壁 / 室内の床 /
  水 / 坂（右上がり・左上がり）。
- ステージは `STAGE_DEFS`（1＝ともだちの みち / 2＝まおうの おしろ / 3＝かわ）で定義します。
  - そと（`MAIN_*` / `CS_*` / `S2_*` の配列）… 地面・足場・坂・水・★・敵・部下・リンゴ・
    おうちのドア・看板を配列で定義。
  - 中（`ROOMS` の配列）… 部屋ごとに 足場・レンガ・★・家具・お助けアイテム・ドアを座標で定義。
- おもな しくみの ありか：
  - つえの まほう … `castBolt` / `updateBolts` / `drawBolts`
  - まおうの てした … `makeMinion` / `drawMinion`
  - リンゴと お助けアイテム … `makeItems` / `takeItem` / `drawItems`
  - ★50この もん … ステージ定義の `gate` / `openGate` / `drawGate`
  - おうさま … `makeBoss` / `updateBoss` / `hurtBoss` / `drawBoss`
- すがたの性能は `FORMS`（大きさ・速さ・ジャンプ力・重力）にまとまっています。
- 文字は Google Fonts（M PLUS Rounded 1c / Mochiy Pop One）。オフラインでも代替フォントで動きます。
